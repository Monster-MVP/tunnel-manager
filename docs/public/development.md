# 开发与协作说明

## 开发入口

安装、开发、构建与使用以根目录 [README](../../README.md) 为入口。后端为静态资源、API和WebSocket提供同一loopback origin，Vite独立服务没有完整认证桥接。

Python和Node依赖分别由`uv.lock`、`package-lock.json`锁定。修改依赖应解释打包和许可影响。只使用项目内隔离runtime，不对用户真实运行通道进行故障注入。

## 所有权和安全

发现的SSH、tinyproxy、Clash和launchd均为外部资源，只读观察。数据库PID不构成控制依据。控制前验证自有进程句柄、创建时间、生成配置与socket身份；不匹配则拒绝，不结束其他进程来释放端口。

使用绝对可执行路径和参数数组，不执行未经审查SSH Config指令。保留主机指纹、TLS、Cookie/CSRF/Origin和loopback约束，不通过全局kill、关闭认证或`0.0.0.0`监听排错。

模型调用与凭据读取分开授权。Key只在远端解析并发给用户核对目标，不返回Mac、写日志或入库。不自动重试付费请求；开发使用明确合成凭据和隔离TLS服务。

## 验证与发布

基础、隔离网络、冻结App和浏览器测试有不同前提，以README分层命令为准。所有缓存、报告、临时文件在项目`var`与`.run`，保留失败，不删除断言取得通过。

UI修改需检查实际截图、中文流程、主题、桌面尺寸、字体缩放和键盘访问。真实API夹具不能替代用户服务器验收，截图和数量不能代替独立视觉结论。运行中的默认App保持不变，构建/更新先处理其明确授权的生命周期。

源码首次发布不导入维护者私人历史或机器专属激活记录。不提交真实配置、私钥、Key、数据库、票据、目录书签、完整环境和私人报告。测试使用合成值和保留域名；项目尚无自选LICENSE，不能自行宣称开源授权。
